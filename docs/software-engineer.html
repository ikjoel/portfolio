Engineering practice

How I keep software correct as it grows.

  • Write down what must always be true, then test exactly that.
  • Compute state from facts (dates, ledgers) instead of storing it.
  • Prefer small, pure functions for logic, so it can be tested without a browser or a server.
  • Measure before and after every performance claim.
  • Fail safe: a guard fails open, a repair has an undo, a licence check refuses clearly.
  • Keep a written decision for every trap I find, so no one falls in twice.
