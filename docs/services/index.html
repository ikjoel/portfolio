(What I do)

Services that keep things clear.

I can join your team as a front-end engineer, or take a project from wireframe to deployment.

(a)

Front-end development

Responsive, accessible interfaces in semantic HTML, CSS and JavaScript, with components you can reuse.

(b)

Figma to code

I turn designs into working pages, keeping spacing, colour and type in shared tokens so nothing drifts.

(c)

Progressive web apps

Installable, fast apps with offline fallbacks and a cache policy that is safe for personal data.

(d)

Full-stack web apps

Laravel, ASP.NET Core or Node.js with databases, payments, email and deployment on Linux.

(e)

Performance and accessibility

Measured speed on slow devices, keyboard and screen-reader basics, print and dark-mode styles.

How I work

Understand

I start with the user’s words and one sentence on what hurts today.

Wireframe

Grey boxes first: layout, order and the one main action.

Design

Colour, type and states in a small token set.

Build

Semantic HTML, CSS variables and reusable components, mobile first.

Check

Keyboard, contrast, empty, loading and error states, print and small screens.

Learn

Watch real use and fix the real problem.
